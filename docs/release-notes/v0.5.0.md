A pull request can now be reviewed end to end: line comments on the diff, then a
verdict, without opening a browser.

## New

**`S` reviews.** It opens a form from any tab: approve, request changes or
comment, with a summary. On your own pull request it offers comment alone, since
GitHub lets an author do nothing else. `esc` keeps the verdict and summary for
the next time the form opens, and so does a refused submit.

**`c` on Files opens a thread on the code.** It comments on what the cursor
names: the selection if there is one, else the row, else the hunk, else the
whole file. The box opens under the code it answers.

**Pending reviews.** A thread written on Files joins your pending review, or
starts one, and reads `pending` until you submit. Nobody else sees it until
then. The review sits at the end of the conversation as a card with its comments
hanging off it, and the header counts them. `S` or `⏎` on the card submits it
with every comment in it, and `D` discards it behind a confirm. While one is
pending, a reply to a thread joins it, as GitHub does.

## Changed

**`ctrl+s` posts, in place of `ctrl+⏎`.** Most Linux terminals never deliver
`ctrl+⏎` to the program, so a comment there could not be sent. `ctrl+s` also
merges from anywhere in the merge form.

## Install

macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-octo/main/install.sh | sh
```

Windows:

```powershell
irm https://raw.githubusercontent.com/praxis-labs-io/zen-octo/main/install.ps1 | iex
```

Each platform on arm64 and amd64, with no Go needed. Both installers check the
download against this release's `checksums.txt` and install nothing that does
not match. `INSTALL_DIR` overrides where the binary lands and `VERSION` pins a
release. Already running zen-octo:

```sh
zen-octo update
```

It rides on the [GitHub CLI](https://cli.github.com)'s token rather than asking
for one of its own, so if `gh auth status` is happy, so is zen-octo. Where a
scope is missing it says which and prints the `gh auth refresh` line.

[Install](https://github.com/praxis-labs-io/zen-octo/blob/main/docs/install.md),
[the guide](https://github.com/praxis-labs-io/zen-octo/blob/main/docs/guide.md),
[the keymap](https://github.com/praxis-labs-io/zen-octo/blob/main/docs/keys.md),
and [configuration](https://github.com/praxis-labs-io/zen-octo/blob/main/docs/configuration.md).

## Known gaps

- No checking a branch out or listing issues. Those still go through `gh` or the
  browser.
- No Homebrew tap.
- Neither installer edits your `PATH`. It says so and gives you the line.
- The POSIX installer needs `sha256sum` or `shasum` on PATH, and refuses where
  neither is.
- Under 56 by 23 the shell draws its size instead of a screen, and drops every
  key but the ways out.
