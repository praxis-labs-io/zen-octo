The first published build of zen-octo, a terminal client for GitHub.

## What it does

A pull request end to end without opening a browser: read it, discuss it, watch
its CI, fix its metadata, merge it. Issues get the same treatment where it makes
sense.

**A list you defined.** Sections are GitHub search queries you wrote, so what is
on screen is whatever you told it to watch: yours, the ones wanting your review,
the ones you are involved in. `{{since:24h}}` in a filter becomes the instant
that long ago, which is the only date shape the search takes.

**Four tabs on a pull request.** The conversation as cards, the diff, the
commits, and the checks. `}` and `{` walk the blocks on whichever tab you are
on, so they mean cards on one and hunks on another.

**Talking works.** `c` comments, scoped on the diff to the line under the cursor.
`r` replies, `R` quotes first, `e` edits your own, `x` resolves a thread, `+`
opens GitHub's eight reactions. `ctrl+e` hands the box to `$EDITOR` for anything
longer than a line.

**Checks you can read.** `/` searches a job's log, `f` jumps to the first
failure, and `r` reruns a job.

**A details rail on `d`**, the only route to five writes: state, labels,
reviewers, assignees and the base branch. It answers at every width the shell
will draw, landing as a column where there is room and over the conversation
where there is not, so a client in a drawer beside an editor is not read-only.

**Merging shows GitHub's own commit message**, per method, rather than one
zen-octo invents. Where the head branch can be deleted it offers that, and where
a protection would be bypassed it says so before the button.

**The diff side by side on `|`**, with the cursor living in one column so a
comment is scoped to the side you are reading.

Writes are optimistic: what you did appears at once, and a refusal reverts it and
says so.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-octo/main/install.sh | sh
```

macOS and Linux, arm64 and amd64. Windows takes the `.zip` from this page, the
installer being a POSIX script. Anything else:

```sh
go install github.com/praxis-labs-io/zen-octo/cmd/zen-octo@v0.1.0
```

It rides on the [GitHub CLI](https://cli.github.com)'s token rather than asking
for one of its own, so if `gh auth status` is happy, so is zen-octo. Where a
scope is missing it says which and prints the `gh auth refresh` line.

[Install](https://github.com/praxis-labs-io/zen-octo/blob/main/docs/install.md),
[the guide](https://github.com/praxis-labs-io/zen-octo/blob/main/docs/guide.md),
[the keymap](https://github.com/praxis-labs-io/zen-octo/blob/main/docs/keys.md),
and [configuration](https://github.com/praxis-labs-io/zen-octo/blob/main/docs/configuration.md).

## Known gaps

- No Homebrew tap.
- The installer checks the download against the release's checksums before it
  installs anything, and refuses where neither `sha256sum` nor `shasum` is on
  PATH.
- One theme ships. The config takes a name for a second when there is one.
- Under 56 by 23 the shell draws its size instead of a screen, and drops every
  key but the ways out.
